# Inventory Manager

A browser-based application for managing product inventory.

## Features

- Product records
- Stock quantities
- Inventory value

## How to Use

Enter product names, quantities and unit prices.

## Technologies

- HTML
- CSS
- JavaScript

## Running Locally

Open `index.html` in a modern web browser.
## Manual Testing Checklist

- [ ] Add a product with a valid quantity and price.
- [ ] Verify the displayed stock value.
- [ ] Reject negative quantities and remove a product.

### Test Notes

Record the observed result and any reproducible issue after running the tests.
